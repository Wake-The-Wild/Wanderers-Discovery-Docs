# Wanderer's Discovery documentation

Official guides for players, server owners and creators using Wanderer's Discovery.
WD adds persistent location discoveries, themed HUD banners, contextual sounds,
stable village names and exploration advancements.

## Guides

- [Installation](docs/installation.md) and [player guide](docs/player-guide.md)
- [Settings](docs/settings.md) and [supported locations](docs/locations.md)
- [Custom discoveries](docs/datapacks.md) and [JSON field reference](docs/discovery-schema.md)
- [Banner format](docs/discovery-banner-layout.md), [resource packs](docs/resource-packs.md) and [sounds](docs/sounds.md)
- [Mod integrations](docs/integrations.md) and [WildTrack API](docs/wildtrack-api.md)
- [Example packs](examples/README.md) and [troubleshooting](docs/troubleshooting.md)

The [documentation index](docs/README.md) lists all guides.

## Compatibility

These guides describe WD’s supported features and content formats. Select mod
downloads that match your Minecraft version and consult each release’s dependency
requirements. The [compatibility reference](docs/compatibility.md) identifies the
build and pack formats used by the included examples. Documentation is maintained
in one tree; Git records previous revisions.
